# 오늘의 배당·시황 노트

배당과 시황을 초보도 이해하기 쉽게 정리하는 주식 투자 정보 블로그입니다.

- 사이트: https://hwan-yeong.github.io/
- 테마: [PaperMod](https://github.com/adityatelange/hugo-PaperMod) (Hugo)
- 배포: GitHub Actions → GitHub Pages (`main` 브랜치에 push 하면 자동 배포)

## 새 글 쓰는 법

`content/posts/` 폴더에 마크다운 파일을 만들고, 맨 위 머리말에 `title`, `date`, `draft: false`를 적은 뒤
아래에 본문을 쓰면 됩니다. 저장하고 `main`에 push 하면 몇 분 뒤 사이트에 반영됩니다.

## 로컬 미리보기

```bash
hugo server -D
```

브라우저에서 http://localhost:1313 접속. (Hugo 확장판 v0.146 이상 필요)
